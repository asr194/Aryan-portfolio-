# Aryan's Cinematographer Portfolio - Requirements

## Project Overview
Modern cinematographer and video editor portfolio website showcasing Instagram reels and professional work.

## Tech Stack
- **Framework**: Next.js 16.1.1 (React with TypeScript)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Utilities**: React Intersection Observer
